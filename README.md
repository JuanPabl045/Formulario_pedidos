# Sistema de Pedidos de Carne 🥩

Un sistema web profesional diseñado para la gestión y realización de pedidos de carne de manera eficiente. Este proyecto está construido para ser 100% viable en un entorno de producción, ofreciendo una experiencia de usuario fluida y un manejo de datos seguro en tiempo real.

## 🚀 Características Principales

* **Interfaz de Usuario Intuitiva:** Interfaz limpia y responsiva para facilitar a los clientes la selección de productos y realización de pedidos.
* **Gestión en Tiempo Real:** Procesamiento de pedidos instantáneo y sincronización de datos.
* **Arquitectura Escalable:** Preparado para manejar un flujo constante de pedidos y usuarios de manera estable.
* **Backend Serverless:** Infraestructura robusta gestionada a través de Firebase.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
* **Backend & Base de Datos:** [Firebase](https://firebase.google.com/) (Firestore / Realtime Database para la gestión de pedidos).

## ⚙️ Configuración y Despliegue

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/JuanPabl045/Formulario_pedidos.git
   ```
2. **Configurar Firebase:**
   * Crea un proyecto en la [Consola de Firebase](https://console.firebase.google.com/).
   * Registra una nueva aplicación web en el proyecto.
   * Habilita los servicios de Base de Datos (Firestore o Realtime Database) según la estructura de tus datos.
   * Copia el objeto de configuración de Firebase (API key, auth domain, project ID, etc.) y añádelo a tu archivo principal de JavaScript donde inicializas la app.
3. El proyecto puede ser probado abriendo directamente los archivos HTML en tu navegador o, preferiblemente, ser desplegado utilizando **Firebase Hosting** para un entorno de producción completo.
